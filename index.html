What’s in Fin

Accuracy plus useful extras

Virtual Wii Balance Board

Four pressure sensors, calibration data, board button support, battery state, dedicated mappings, and a live weight monitor.

Wii Sports Resort profile

Game-specific accuracy handling for CPU threading and Wii Remote speaker behavior, while respecting per-game overrides.

Direct in-app updates

Fin checks the NVDEMU release, downloads the matching platform package, installs it, and restarts the emulator.

Performance-focused changes

Fin keeps low-risk optimizations separate from user-visible settings, including avoiding unused Balance Board input work.
