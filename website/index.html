WHY NVWII

One clean product layer over a mature emulation core.

Modern UI

Flat dark surfaces, a strong red accent, clear hierarchy, and quick access to the most-used emulator actions.

Wii-first workflow

Fast access to your game library, graphics, controllers, and settings without legacy visual clutter.

Release automation

Windows and macOS builds are produced by GitHub Actions, with tagged releases and a scheduled nightly channel.

Core-focused roadmap

Future nvwii work is organized around correctness, rendering, frame pacing, input latency, and compatibility.

Local by default

nvwii disables upstream analytics and uses its own application identity and user-data folder.

Open source

nvwii remains under GPLv2-or-later, preserving the licensing requirements of the upstream code base.
